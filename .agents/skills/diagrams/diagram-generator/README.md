# skill-diagram-generator

Emit valid Graphviz DOT source for a topic, given a node budget. Use when user says \"diagram this\", \"graphviz X\", \"make a graph of Y [N]\". Uses layout=neato, overlap=false, indexed rectangular nodes. Output is single-line valid DOT with no styling, ready to paste.

## Installation

```
npx skills add https://github.com/chirag127/skill-diagram-generator
```
