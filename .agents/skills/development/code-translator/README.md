# skill-code-translator

Translate source code between programming languages while preserving semantics. Use when user says \"translate this to <lang>\", \"port to <lang>\", \"convert this <lang> to <lang>\". Preserves control flow, adds language-idiomatic patterns, notes stdlib substitutions.

## Installation

```
npx skills add https://github.com/chirag127/skill-code-translator
```
