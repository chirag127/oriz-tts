oriz-tts

A free, 100% client-side text-to-speech web app. Paste text, pick any system voice, dial in rate and pitch, and hear it read aloud with each sentence highlighting as it's spoken.

Open the live app → Source on GitHub llms.txt

This is the about page for the project. The tool itself lives at tts.oriz.in.

What it is

Text-to-speech in the browser — voice, rate and pitch controls, with each sentence highlighting as it's spoken. It runs on the native Web Speech API using the voices already installed on your device.

Key features

  • Every system voice — dozens of languages and accents, no downloads
  • Highlight-as-spoken sentence tracking, to follow along or proofread by ear
  • Rate, pitch and volume knobs, saved on your device
  • Drag-drop or load a .txt / .md file
  • Word/char count and estimated spoken duration
  • Animated waveform synced to playback (respects reduced-motion)
  • Optional AI rewrite for natural narration or a target reading level — degrades gracefully
  • Pause / resume / stop transport

How it's built

  • Client-only Astro (static) + React islands — no backend
  • Native window.speechSynthesis for synthesis
  • g4f AI (no key, multi-provider failover) via @chirag127/oz-ai for the optional rewrite
  • PWA-installable, works offline
  • 100% in-browser — no upload, no signup, no server
